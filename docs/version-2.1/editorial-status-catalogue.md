# Editorial status catalogue

Phase 2.1-C uses `draft`, `pending_review`, `changes_requested`, `approved`, `scheduled`, `published`, `rejected`, and `archived`. Draft and changes-requested content is author-editable; pending content is under review; approved content is eligible for scheduling/publication; only published content is public. Rejected and archived records are retained. Existing records may legitimately have null workflow metadata and no history.

Save-draft requires the existing form rules. Submission additionally requires title, slug, content, author, and a category. Corrections and rejection require notes. Scheduling requires approval and a future application-timezone timestamp.
