# Daily Samvad Project

## Overview

Daily Samvad is a multilingual digital news platform currently running on WordPress.

Current production website:

http://localhost/dailysamvad-old

Target Laravel website:

http://localhost/dailysamvad-new

The new application will replace the existing WordPress CMS while preserving content, SEO value, URLs, categories, authors and media.

## Current WordPress Setup

- Active theme: OceanWP
- Elementor-based sections
- Yoast SEO
- Ad Inserter
- LiteSpeed Cache
- WP Post Author
- Social sharing plugins
- YouTube/video widgets
- Approximately 13,000 published posts
- Hindi, Punjabi and English content
- Existing advertising banners and category-based homepage sections

## Target Application

The new application will be built with:

- Laravel 13.20
- MySQL
- Blade
- Livewire 4.3
- Tailwind CSS
- Filament 5.6
- Redis queues later
- Vite
- React only where justified

## Main Goals

1. Rebuild the current frontend design.
2. Migrate WordPress content.
3. Preserve SEO and URL structure.
4. Create a professional Laravel news CMS.
5. Create reusable WordPress migration tools.
6. Add AI News-Man drafting workflow.
7. Deploy on the same Hostinger VPS.
8. Keep the old WordPress site available until final launch.

## Publishing Workflow

Reporter creates content.

Editor reviews content.

Editor or Admin publishes content.

AI-generated content always starts as draft.
