# Daily Samvad frontend assets

- Put logo and general brand assets in `public/images/frontend/`.
- Put advertisement assets in `public/images/frontend/ads/`.
- Put fallback and empty-state artwork in `public/images/frontend/placeholders/`.
- Put project-owned icons in `public/images/frontend/icons/`.
- Use lowercase, hyphenated filenames such as `daily-samvad-logo.png`.
- Do not depend on WordPress upload paths; copy only approved assets into this structure during a later phase.
